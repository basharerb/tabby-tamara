# نظام ومستودع الركيز للإدارة والمحاسبة والـ ERP 🏢✨

نظام سحابي ومستودعي متكامل لإدارة مبيعات ومخزون ومحاسبة شركة ومستودع **الركيز (Rakeez Warehouse & ERP System)**، مصمم ومبني وفق أعلى المعايير القياسية مع محرك أمان تلقائي وقفل برمز الدخول لحماية البيانات والمستندات المالية.

---

## 🌟 الموديولات والخدمات الرئيسية (Key Modules)

1. **لوحة التحكم والتنفيذ (Executive Dashboard)**:
   - متابعة حية لـ: إجمالي المبيعات، المصروفات التشغيلية، صافي الربح، وقيمة البضاعة في المخزون.
   - تنبيهات المنتجات القريبة من النفاد وأحدث العمليات.

2. **المبيعات وكاشير الفواتير الضريبية (Sales & POS Cashier)**:
   - واجهة كاشير سريعة تتيح إضافة المنتجات وحساب ضريبة القيمة المضافة 15% تلقائياً.
   - إصدار فواتير ضريبية مبسطة معتمدة قابلة للطباعة والمعاينة.
   - خصم الكميات تلقائياً من المستودع فور إصدار كل فاتورة.

3. **إدارة مستودع الركيز والمنتجات (Rakeez Inventory Management)**:
   - متابعة كميات المنتجات في المستودع، أسعار الشراء والتكلفة، أسعار البيع، وهامش الربح لكل منتج.

4. **المصروفات والتكاليف التشغيلية (Expenses & Purchases)**:
   - تسجيل إيجارات المقرات، الكهرباء والاتصالات، ومشتريات البضائع وحساب الضريبة المستردة.

5. **التقارير المالية والإقرار الضريبي (Financial Reports & 15% VAT)**:
   - قائمة الأرباح والخسائر الملخصة (P&L Statement).
   - ملخص الإقرار الضريبي لهيئة الزكاة والضريبة والجمارك.

6. **إدارة الموظفين والرواتب (HR & Payroll)**:
   - دليل الموظفين، المسميات الوظيفية، وإجمالي مسير الرواتب الشهري.

7. **نظام الأمان التلقائي لمستودع الركيز (3-Minute Auto-Lock Security)**:
   - قفل النظام برمز الدخول تلقائياً بعد 3 دقائق من الخول أو الخروج لحماية خصوصية بيانات مستودع الركيز.

## 🚀 التشغيل المحلي (Local Setup)

```bash

npm install

# 2. تشغيل خادم التطوير
npm run dev

# 3. بناء النسخة النهائية (Production Build)
npm run build
```
